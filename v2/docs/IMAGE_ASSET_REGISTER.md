# TShirtSwiss Image Asset Register

## Purpose

This register tracks the final approved image files used across the TShirtSwiss website.

Do not mark an image approved until its source, licence, crop, filename, alt text and responsive behaviour have been checked.

## Status key

- `Needed` — image requirement confirmed but no candidate selected
- `Shortlisted` — one or more candidates under review
- `Approved source` — source image approved but not optimised
- `Optimised` — web files prepared
- `Implemented` — added to page
- `QA approved` — desktop, tablet, mobile, accessibility and performance checks complete

## Optimisation checklist

Before changing status to `Optimised`:

- [ ] Correct crop created
- [ ] Mobile crop created where necessary
- [ ] AVIF exported
- [ ] WebP exported
- [ ] JPG fallback exported where required
- [ ] Width and height attributes recorded
- [ ] File size checked
- [ ] Metadata removed
- [ ] Visual comparison completed against master source
- [ ] Filename matches convention

## Usage rules

- Do not reuse a hero image on another page.
- Supporting images may be reused only when they describe the same process and the reuse is recorded.
- Product and industry pages should not share the same primary image.
- Maintain one authoritative source file for every approved asset.
- When an asset is replaced, record the retired filename and reason in the change log.
