# Full Site Image and Structure Audit

Purpose: audit every public page in the GitHub Pages prototype while preserving the existing page structures and written content. Image changes should make each page more aligned with its topic, without redesigning the page or rewriting copy.

Navigation reference: `pages/services/screen-printing/index.html`

## Audit rules

- Keep current page structures.
- Keep current written content unless a separate copy-edit task is requested.
- Replace only images that are generic, repeated too often, off-topic, or poorly aligned with the page focus.
- Keep image dimensions/layout patterns already used by each page.
- Preserve current hero, section, card, FAQ, CTA, and footer structure.
- Check mobile cropping before approving an image choice.
- Use topic-specific alt text.
- Work in small batches so changes are easy to review and revert.

## Global checks for every page

- Header/menu uses the Screen Printing page navigation standard.
- Hero image matches the page topic.
- Supporting section images match the section topic.
- Image aspect ratio works with the existing layout.
- Mobile crop remains useful at narrow widths.
- Alt text describes the page-specific image context.
- CTA links still point to correct pages.
- Footer remains unchanged unless already part of the page standardisation scope.
