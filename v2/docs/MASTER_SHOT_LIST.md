# TShirtSwiss Master Photography Shot List

## Purpose

This document is the production brief for photographing or sourcing the complete TShirtSwiss image library.

Each page should receive a balanced set of hero, product/application, process and detail imagery. Existing page structures must remain unchanged unless separately approved.

## Universal capture rules

- Capture horizontal hero-safe compositions with the main subject positioned left and right in separate variations where possible.
- Capture a second, tighter crop for mobile.
- Photograph real garments or realistic approved samples.
- Keep customer trademarks out of frame unless usage permission is documented.
- Capture each important detail in both contextual and close-up form.
- Maintain consistent colour, exposure and white balance across each page set.

## Capture completion rule

A page set is complete only when:

- The hero has a desktop and mobile-safe option.
- Every key section has a unique relevant image.
- Product/process details are sharp and technically correct.
- File rights and releases are recorded.
- The set can be colour-matched to the existing approved site design.
