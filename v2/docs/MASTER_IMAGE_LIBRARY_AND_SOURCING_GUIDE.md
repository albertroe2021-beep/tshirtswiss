# TShirtSwiss Master Image Library and Sourcing Guide

## Purpose

This is the master sourcing document for replacement imagery across the English-language TShirtSwiss website.

Use it together with:

- `IMAGE_REPLACEMENT_REGISTER.md`
- `BRAND_PHOTOGRAPHY_STYLE_GUIDE.md`
- `MASTER_SHOT_LIST.md`
- `IMAGE_ASSET_REGISTER.md`
- `IMAGE_IMPLEMENTATION_TRACKER.md`

The image IDs below align with the page groups already defined in the replacement register.

## Sourcing priority

1. TShirtSwiss-owned photography
2. Commissioned factory, product or customer-context photography
3. Licensed premium stock with strong subject relevance
4. Carefully selected free stock only where it meets commercial and visual requirements

Do not select an image because it is attractive if it does not accurately support the page content.

## Source requirements

Every selected asset must have:

- A recorded source URL or repository path
- Confirmed commercial-use rights
- Original pixel dimensions
- Photographer or supplier attribution where required
- A descriptive final filename
- Desktop, tablet and mobile crop notes
- Page-specific alt text
- Approval status

## Global search vocabulary

Combine the exact product, industry or service with one or more of these terms:

- apparel manufacturing
- garment production
- clothing factory
- custom uniforms
- branded workwear
- private label clothing
- apparel quality control
- garment packaging
- embroidery machine
- screen printing
- sublimation printing
- heat press
- fabric inspection
- garment sampling
- garment tech pack
- clothing fulfilment

Avoid broad searches such as `business team`, `factory`, `office meeting`, `shipping` or `fashion` without apparel-specific qualifiers.

## Search and selection scoring

Score every candidate from 1 to 5 in each category:

| Criterion | Weight |
|---|---:|
| Exact page relevance | 30% |
| Product/process visibility | 20% |
| Composition and crop flexibility | 15% |
| Brand-style fit | 15% |
| Technical quality | 10% |
| Authenticity | 5% |
| Licence clarity | 5% |

Reject any candidate scoring below 4/5 for exact page relevance, regardless of its total score.

## Final output requirements

- Hero: AVIF/WebP at 1800-2200 px wide, plus mobile crop where necessary.
- Split image: AVIF/WebP at 1200-1400 px wide.
- Card image: AVIF/WebP at 800-1000 px wide.
- Thumbnail: 1200x675 source crop.
- Preserve a high-quality master outside the web-delivery folder.
- Record all final assets in `IMAGE_ASSET_REGISTER.md` before implementation.
